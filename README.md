# Kayros CRM

CRM-система для сервисного центра по ремонту смартфонов.  
Публичный сайт + панель управления + VK-бот с ИИ-ассистентом.

**Репозиторий:** https://github.com/dmitriyshock/main_diplom

---

## Стек

| Компонент   | Технология                         |
|-------------|------------------------------------|
| Бэкенд      | Django 6                           |
| База данных | PostgreSQL (prod) / SQLite (dev)   |
| Фронтенд    | Tailwind CSS                       |
| Статика     | WhiteNoise                         |
| VK-бот      | vkbottle 4.8.2                     |
| ИИ          | Groq API — llama-3.3-70b-versatile |

## Быстрый старт (локально)

```bash
git clone --branch work https://github.com/dmitriyshock/main_diplom && cd main_diplom

python -m venv .venv
source .venv/bin/activate     # Linux/Mac
.venv\Scripts\activate        # Windows

pip install -r requirements.txt
```

Создать `.env`:

```env
DEBUG=True
SECRET_KEY=любой-ключ
ALLOWED_HOSTS=localhost,127.0.0.1
USE_SQLITE=True
SQLITE_NAME=db.local.sqlite3
```

Если нужно начать с демонстрационных данных из репозитория, один раз скопируйте
`db.sqlite3` в `db.local.sqlite3`; исходный файл не изменяется.

```bash
python manage.py migrate
python manage.py seed_data          # тестовые данные + admin/admin123
python manage.py seed_iphone_prices # опционально: прайс iPhone

python run.py --site-only
```

| Адрес                      | Описание   |
|----------------------------|------------|
| http://127.0.0.1:8000      | Сайт       |
| http://127.0.0.1:8000/crm/ | CRM-панель |

Логин: `admin` / `admin123`

## Деплой на сервер

### Автоустановка (рекомендуется)

```bash
wget https://raw.githubusercontent.com/dmitriyshock/main_diplom/work/setup.sh
sudo bash setup.sh
```

Скрипт сделает всё сам:

- Установит пакеты: python3, git, postgresql, ufw
- Создаст БД PostgreSQL со случайным паролем
- Создаст виртуальное окружение, установит зависимости
- Сгенерирует `.env` с `SECRET_KEY` и вашим IP
- Применит миграции, соберёт статику
- Предложит создать администратора
- Установит команду `kayros` в `/usr/local/bin/`
- Пропишет короткие алиасы в `~/.bashrc`
- Откроет порт 8000 через UFW

После установки:

```bash
source ~/.bashrc
status    # проверить состояние
start     # запустить
```

### Ручная установка

```bash
cd /opt
git clone --branch work https://github.com/dmitriyshock/main_diplom main_diplom
cd main_diplom

python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

`.env` для продакшена:

```env
DEBUG=False
SECRET_KEY=длинный-случайный-ключ
ALLOWED_HOSTS=ваш_ip,localhost
USE_SQLITE=False
DB_NAME=kayros_crm
DB_USER=kayros
DB_PASSWORD=пароль
DB_HOST=localhost
DB_PORT=5432
```

```bash
sudo -u postgres psql -c "CREATE USER kayros WITH PASSWORD 'пароль';"
sudo -u postgres psql -c "CREATE DATABASE kayros_crm OWNER kayros;"

python3 manage.py migrate
python3 manage.py createsuperuser
python3 manage.py collectstatic --noinput

ufw allow 8000
python3 run.py --host 0.0.0.0 --port 8000
```

## VK-бот

### Уровни доступа

| Статус            | Доступно                                                    |
|-------------------|-------------------------------------------------------------|
| Незарегистрирован | Только «💰 Узнать цены»                                     |
| Зарегистрирован   | Цены, запись на ремонт, выкуп устройств, ИИ-чат, контакты  |

### Регистрация

Клавиатура незарегистрированного пользователя:

```
[💰 Узнать цены      ]
[📝 Зарегистрироваться]
```

При нажатии «📝 Зарегистрироваться» бот автоматически получает имя пользователя из ВКонтакте.  
Пользователь вводит номер телефона вручную, затем бот запрашивает согласие на обработку ПД (ФЗ-152):

- **✅ Согласен** — клиент создаётся в базе, открывается полное меню
- **❌ Не соглашаюсь** — доступ остаётся ограниченным, кнопка регистрации доступна снова

Согласие запрашивается один раз. При последующих обращениях оно не запрашивается повторно.

### Полное меню (после регистрации)

```
[💰 Узнать цены]  [📅 Записаться]
[📞 Контакты   ]  [📦 Выкуп     ]
```

> Свободный чат с ИИ-ассистентом доступен в любое время — просто напишите сообщение без нажатия кнопок.

### Возможности бота

| Функция        | Описание                                                                    |
|----------------|-----------------------------------------------------------------------------|
| 💰 Узнать цены | Поиск по прайсу через ИИ (доступно всем)                                   |
| 📅 Записаться  | Пошаговая запись: имя и телефон подставляются из профиля                   |
| 📦 Выкуп       | ИИ-оценка стоимости б/у устройства + запись на сдачу                       |
| 📞 Контакты    | Адрес, телефон, часы работы из настроек CRM                                |
| ✉️ Свободный чат | Написать любое сообщение — ответит ИИ-ассистент, понимает намерение записи |

---

### Выкуп устройств

Пошаговая оценка стоимости б/у смартфона из 5 шагов:

| Шаг | Вопрос               | Ввод                                                                           |
|-----|----------------------|--------------------------------------------------------------------------------|
| 1   | Модель устройства    | Свободный текст (iPhone 13, Samsung S21…)                                      |
| 2   | Объём памяти         | Кнопки: 64 / 128 / 256 / 512 ГБ / 1 ТБ / Другой                              |
| 3   | Состояние экрана     | Кнопки: ✨ Отличное / 👍 Хорошее / 😐 Удовлетворительное / 💔 Повреждён       |
| 4   | Ёмкость аккумулятора | Кнопки: 🔋 90–100% / 80–89% / 70–79% / 🪫 Ниже 70% / ❓ Не знаю             |
| 5   | Состояние корпуса    | Кнопки: ✨ Отличное / 👍 Хорошее / 😐 Удовлетворительное / 💔 Повреждён       |

После ответов ИИ рассчитывает ориентировочный диапазон цен выкупа в рублях с учётом рыночных цен 2025 года.

**По итогу оценки бот предлагает записаться:**

```
📅 Хотите записаться на сдачу устройства прямо сейчас?

[✅ Записаться на выкуп]
[❌ Нет, спасибо       ]
```

При записи бот задаёт только имя и телефон (остальное уже известно из оценки).  
Заявка попадает в общую таблицу записей CRM — в поле «Проблема/Комментарий» автоматически прописываются все параметры устройства:

```
Выкуп: iPhone 13 | 128 ГБ | экран: Хорошее | АКБ: 80–89% | корпус: Отличное
```

Мастер видит полную информацию об устройстве сразу при открытии заявки.

---

### Умная запись (через чат)

Бот понимает намерение записаться в свободном тексте и сам извлекает данные:

> *«хочу записаться на завтра в 16:00, iPhone X не включается»*

Из одного сообщения бот определит устройство, проблему, дату и время.  
Имя и телефон берутся из профиля клиента автоматически.  
Дату и время можно пропустить кнопкой «⏭ Пропустить».

---

### ИИ — цепочка резервных моделей

Если основная модель достигла суточного лимита токенов (100k на free tier),  
бот автоматически переключается на следующую. У каждой модели свой независимый лимит.

| Приоритет | Модель                  | Описание       |
|-----------|-------------------------|----------------|
| 1         | llama-3.3-70b-versatile | Основная       |
| 2         | llama-3.1-8b-instant    | Быстрый резерв |
| 3         | gemma2-9b-it            | Google Gemma 2 |
| 4         | mixtral-8x7b-32768      | Mistral        |

## Частые проблемы

**Не грузятся стили после `git pull`**  
Выполните `restart` — статика пересобирается автоматически при каждом старте.  
Или вручную: `python3 manage.py collectstatic --noinput`

**Бот не запускается**  
Вставить токен: **CRM → Настройки → VK-бот** → поле «Токен VK-бота».  
Получить на [vk.com/dev](https://vk.com/dev) в настройках сообщества → работа с API.

**ИИ не отвечает / выкуп не оценивает**  
Вставить ключ: **CRM → Настройки → VK-бот** → поле «Groq API Key».  
Получить на [console.groq.com/keys](https://console.groq.com/keys) (начинается с `gsk_`).

**Ошибка 429 — лимит токенов Groq**  
Бот автоматически переключается на резервную модель — никаких действий не требуется.  
Лимит восстанавливается ежесуточно. При необходимости — обновить план на [console.groq.com](https://console.groq.com/settings/billing).

**Бот завис или не реагирует**  
Написать «Начать» или «/start» — сбрасывает состояние диалога.
